GasolinIA

Modelo de machine learning que prevê o consumo de combustível (km/L) de um veículo com base em cinco características técnicas, usando regressão linear múltipla.

  • Python
  • scikit-learn
  • Regressão Linear
  • Álgebra Linear
  • Streamlit

Kauan Magri · Luiz Felipe — Raciocínio Matemático para Computação, Prof. Eduardo Z. Sartoretto, 2026.

Apresentação (PDF) Relatório técnico (PDF)

O problema

Prever o consumo médio de combustível de um veículo que o modelo nunca viu antes, com base apenas nas suas características técnicas — sem precisar testá-lo na prática. É um problema de regressão supervisionada: a saída (km/L) é um valor numérico contínuo, não uma categoria.

Economia

Ajuda motoristas a escolher carros mais eficientes antes da compra.

Sustentabilidade

Menor consumo estimado significa menos emissões de CO₂.

Automação

A IA substitui testes físicos de consumo, que são custosos e demorados.

Dados utilizados

A base foi construída com 15 veículos reais do mercado brasileiro, do Fiat Uno ao BMW M3 e à Ford F-150 — uma matriz de features X de 15×5, acima do mínimo de 10×5 exigido pelo trabalho.

FeatureTipoDescriçãoExemplo
Cilindrada (L)NuméricaTamanho do motor em litros1.0 a 5.0
Peso (kg)NuméricaMassa total do veículo870 a 2200 kg
Potência (cv)NuméricaForça do motor em cavalos-vapor65 a 510 cv
Aceleração (s)NuméricaTempo de 0 a 100 km/h3.9 a 15.0 s
Ano do modeloNuméricaAno de fabricação do veículo2010 a 2023

Variável alvo (y): consumo médio em km/L de cada veículo — o valor que o modelo aprende a prever a partir das cinco features acima.

Modelo e treinamento

O modelo utilizado é a Regressão Linear Múltipla, implementada com LinearRegression do scikit-learn. O treinamento segue a equação:

ŷ = β₀ + β₁·Cilindrada + β₂·Peso + β₃·Potência + β₄·Aceleração + β₅·Ano

Os coeficientes β são calculados pelo método dos Mínimos Quadrados Ordinários (OLS), que minimiza a soma dos erros ao quadrado entre o valor previsto e o valor real.

A interpretação dos coeficientes mostrou que veículos mais pesados tendem a consumir mais, carros que demoram mais para acelerar (geralmente com motores menores) tendem a ser mais econômicos, e veículos mais novos são, em média, mais eficientes.

Limitações do modelo

  • Base pequena: com apenas 15 amostras, o modelo pode não generalizar bem para veículos muito diferentes dos presentes no dataset.
  • Linearidade: a regressão linear assume uma relação linear entre features e consumo, o que pode não valer em todos os casos.
  • Features ausentes: tipo de combustível, tração 4x4, tipo de transmissão e condições de uso não foram considerados.
  • Outlier: o Toyota SW4 teve o maior erro (-2.6 km/L), provavelmente por ser um veículo pesado com motor relativamente econômico para seu porte.
